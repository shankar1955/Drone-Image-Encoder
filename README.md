# Low-Bitwidth-Hardware-Encoder
A lightweight RTL-based image encoder for micro-drones, implementing DCT, Quantizer, Zig-Zag and RLE for low-bitwidth grayscale compression. Designed with fixed-point datapaths and clock gating for low power. Runs in real time on Artix-7 using &lt;20% LUTs with UART output for easy SoC integration.
